# «Диверсант» (из шаблона «Шина 75»)

Демо-сайт шиномонтажа. Сделан по AI-RULES v3 (`../AI-RULES.md`), схема первого экрана A.

## Как переделать под клиента (10–15 минут)

1. Скопируй папку целиком и назови по клиенту латиницей: `shinomontazh-kolesnik`.
2. Открой `data.js` и поменяй:
   - `name`, `title`, `description` — название и строка для поиска;
   - `phone`, `whatsapp` (только цифры, с 7 в начале), `address`, `hours`, `gis` (ссылка на карточку в 2ГИС);
   - тексты в `hero`, `calc`, `gallery`, `services`, `contacts`;
   - цены в `calc.types[].prices`: радиус → цена за 4 колеса.
3. Положи фото в `assets/` и пропиши пути в `data.js`.

Переносы строк в заголовках — это отдельные элементы массива: `["Переобуем", "за 40 минут"]`. Неразрывные пробелы после предлогов и между числом и ₽ скрипт ставит сам.

## Какие файлы заменить перед сдачей

| Где в data.js | Что положить | Размер |
|---|---|---|
| `hero.video` + `hero.poster` | видео первого экрана без звука (mp4) и его первый кадр (jpg); справа должна быть тёмная пустая зона под текст | 1280×720 |
| `calc.types[].rim` | диск анфас для каждого типа машины; в `cx`, `cy`, `r` указать центр и радиус обода в долях ширины фото — сайт вырежет диск по кругу и вставит в нарисованную шину | 1200 по ширине |
| `gallery.items[0–2].src` | бокс, работа мастера, склад шин | 1000 по ширине |
| `contacts.image` | мастер у машины или въезд в бокс | 1200 по ширине |

Сайт сам переводит все фото в ч/б, чтобы они смотрелись одинаково.

Сейчас в `assets/` лежат фото с Unsplash и Pexels (бесплатные, можно для коммерции): `rim-*.jpg` — диски, `gallery-*.jpg` — галерея, `contacts.jpg`. Перед сдачей клиенту лучше заменить их на его настоящие фото. Диск — только анфас, иначе он съедет с центра колеса.

Видео делается «маятником»: вперёд и назад, чтобы цикл шёл без рывка. `8` — секунда, до которой видео идёт чисто (без склейки в конце), `191` = 8 × 24 кадра − 1:

```bash
ffmpeg -i исходник.mp4 -filter_complex "[0:v]trim=0:8,setpts=PTS-STARTPTS,split[a][b];[b]reverse,trim=start_frame=1:end_frame=191,setpts=PTS-STARTPTS[r];[a][r]concat=n=2:v=1:a=0,split[d][m];[d]scale=1920:-2:flags=lanczos,unsharp=5:5:0.5[hd];[m]scale=1280:-2:flags=lanczos[sd]" -map "[hd]" -an -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -movflags +faststart assets/hero.mp4 -map "[sd]" -an -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -movflags +faststart assets/hero-mobile.mp4
```

`hero.mp4` (1920, ~7 МБ) — для компьютера, `hero-mobile.mp4` (1280, ~1,8 МБ) — для телефона.

## Как посмотреть локально

В папке `мои проекты` запустить превью `shina75` или:

```bash
py -3 -m http.server 5500 --directory "сайты/shina75-template"
```

и открыть http://localhost:5500

## Окно администратора (admin.html)

Цены за переобувку, радиусы, размеры шин и список услуг лежат в `prices.js`. Сайт читает их оттуда, а `admin.html` их правит. Он сохраняет файл прямо в репозиторий GitHub (`repo` и `branch` в `data.js`), и через минуту GitHub Pages показывает новые цены.

Ключ для администратора (делается один раз):
1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: Only select repositories → репозиторий этого сайта.
3. Permissions → Repository permissions → Contents: Read and write.
4. Срок: максимальный. Ключ отдать администратору: он вставит его на странице `/admin.html`.

Ключ даёт доступ только к этому репозиторию. Если он утечёт, его можно удалить на той же странице GitHub и сделать новый.

На localhost админка открывается без ключа, но сохранять не может: только для проверки вида.
